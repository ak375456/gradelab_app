# Downloaded fonts

The bundled font selector includes all supplied static faces of Magari, Pirata One,
Hopeless Romantic and Syne. Raleway was already bundled with the same 18 static
faces supplied in Downloads. These families and their styles are free to select
and export under GradeLab's access policy.

- Magari by [GraphicsFamily](https://graphicsfamily.com/downloads/Magari-Font-Family/).
  [Free Fonts by GraphicsFamily](https://graphicsfamily.com/downloads/category/fonts/).
  The original download, attribution notices and accompanying files are preserved
  in `Magari-Font-Family.bundle`; the font files are unmodified.
- Pirata One: Rodrigo Fuenzalida and Nicolas Massi. See `PirataOne-OFL.txt`.
- Syne: The Syne Project Authors. See `Syne-OFL.txt`.
- Raleway: See `Raleway-OFL.txt`.
- Hopeless Romantic: the unmodified `HopelessRomantic-Regular.otf` supplied by the
  app owner. No separate license notice accompanied this download.

Only the static Syne faces are bundled to avoid registering the variable font
and static fonts under the same PostScript names. Projects store those stable
PostScript names, and preview and export use the same CoreText renderer.
