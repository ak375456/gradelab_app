# App Store badge

`download-on-the-app-store.svg` is the original black English badge supplied by
Apple at:

https://developer.apple.com/assets/elements/badges/download-on-the-app-store.svg

`download-on-the-app-store.png` is a high-resolution rasterization for the video
renderer. The artwork, colors, lettering, proportions and border are unchanged.

Reference: https://developer.apple.com/app-store/marketing/guidelines/
