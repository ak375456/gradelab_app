# GradeLab marketing assets

Finished marketing files were separated from the app repository on 2026-10-13.
This folder contains one canonical copy of each retained asset. The app source
remains at `/Users/aftab/Desktop/dummy name/`.

- `App Store/iPhone/1206x2622/`: seven ordered screenshots per locale for the
  medium-display group used in App Store Connect. Cards 01–06 precede masking.
  Upload all seven for a complete gallery; a newly uploaded set replaces the
  inherited screenshots for that size group.
- `App Store/iPhone/1242x2688/` and `App Store/iPad/2064x2752/`: masking/tracking
  cards for the other previously prepared device groups.
- `App Store/`: existing iPad/Mac galleries, Color Warper/Fine Tune cards,
  localized header/search artwork and reusable listing metadata. Folder names
  identify device, dimensions or topic. Native app UI in the artwork is English;
  localized marketing headlines use each locale.
- `Social/2026-10-masking-tracking-carousel/`: the three-slide Instagram and
  TikTok campaign, caption, delivery ZIP, generated masters and generation record.
  Instagram PNGs are 1080×1350; TikTok PNGs are 1080×1920. `export.py` still
  works from its own directory because its selected masters are included.
- `Video Outros/`: current three-second Spectrum videos in portrait/landscape.
- `App Previews/`: the previously prepared preview videos.
- `Brand References/`: icon artwork, alpine-lake assets and native mask/tracking
  captures useful for future visual work. These are references, not upload files.

Old release notes, promotional drafts, superseded creative variants, duplicate
ZIPs/extracted galleries, contact sheets and temporary rendering scripts were
removed. Obsolete files from this cleanup are recoverable in macOS Trash.
